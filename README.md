# Entre Linhas e Dados

## Experiências Computacionais no Desenho Têxtil

Este repositório contém o código desenvolvido no âmbito da dissertação de Mestrado em Design e Multimédia da Universidade de Coimbra.

## Sobre o projeto

Este projeto explora a tradução de dados pessoais significativos em instruções de tecelagem compatíveis com a técnica tradicional de Almalaguês.

O sistema utiliza regras computacionais determinísticas para transformar dados pessoais em parâmetros de tecelagem e gerar instruções sequenciais para a execução do tecido.

## Dados de entrada

O sistema utiliza os seguintes dados:

- Nome
- Data de nascimento
- Local de nascimento
- Pessoa importante
- Lugar significativo
- Data marcante

## Funcionamento

Os dados fornecidos pelo utilizador são processados através de regras computacionais que determinam diferentes características da estrutura do tecido.

O sistema gera instruções de tecelagem que são posteriormente interpretadas e executadas no tear, mantendo a tecedeira como parte fundamental do processo de materialização.
